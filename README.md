# TechService — сайт компьютерной помощи в Сарыагаше

Одностраничный сайт-визитка для услуг по настройке, ремонту и обслуживанию компьютеров и ноутбуков в Сарыагаше (Казахстан). Сайт доступен на двух языках — русском и казахском.

## Возможности

- Двуязычный интерфейс (русский / казахский) с выпадающим меню выбора языка
- Разделы: главная, услуги, прайс-лист, «как проходит работа», контакты
- Адаптивная вёрстка для компьютеров, планшетов и телефонов
- Плавная прокрутка по якорным ссылкам
- Кнопки быстрой связи через Instagram

## Технологии

- [Next.js](https://nextjs.org/) (App Router)
- [React](https://react.dev/) + TypeScript
- [Tailwind CSS](https://tailwindcss.com/) (подключён) и собственные стили в `globals.css`
- [lucide-react](https://lucide.dev/) — иконки

## Быстрый старт

Требуется установленный [Node.js](https://nodejs.org/) версии 18 или новее.

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/YOUR_USERNAME/techservice.git
cd techservice

# 2. Установите зависимости
npm install

# 3. Запустите режим разработки
npm run dev
```

После запуска откройте [http://localhost:3000](http://localhost:3000) в браузере.

## Как изменить содержимое

Все тексты и данные находятся в начале файла `app/page.tsx`:

- `copy` — заголовки и подписи на русском (`ru`) и казахском (`kz`)
- `services` — список услуг
- `prices` — прайс-лист
- `steps` — этапы работы
- `instagram` — ссылка на профиль в Instagram

Чтобы изменить цены или добавить услугу, отредактируйте соответствующий массив **для обоих языков**, чтобы данные совпадали.

### Добавление нового языка

1. Добавьте код языка в тип `Language`
2. Добавьте переводы в объекты `copy`, `services`, `prices` и `steps`
3. Добавьте запись в массив `languages` — выпадающее меню обновится автоматически

## Деплой

Проще всего развернуть сайт на [Vercel](https://vercel.com/new):

1. Загрузите проект на GitHub
2. Импортируйте репозиторий на Vercel
3. Нажмите **Deploy** — при каждом push в ветку `main` сайт будет обновляться автоматически
