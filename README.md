# TechService — сайт компьютерной помощи в Сарыагаше

Одностраничный сайт-визитка для услуг по настройке, ремонту и обслуживанию компьютеров и ноутбуков в Сарыагаше (Казахстан). Сайт доступен на двух языках — русском и казахском.

## Возможности

- Двуязычный интерфейс (русский / казахский) с выпадающим меню выбора языка
- Разделы: главная, услуги, прайс-лист, «как проходит работа», контакты
- Адаптивная вёрстка для компьютеров, планшетов и телефонов
- Плавная прокрутка по якорным ссылкам
- Кнопки быстрой связи через Instagram

## Технологии

- [Next.js](https://nextjs.org/) (App Router)
- [React](https://react.dev/) + TypeScript
- [Tailwind CSS](https://tailwindcss.com/) (подключён) и собственные стили в `globals.css`
- [lucide-react](https://lucide.dev/) — иконки

## Быстрый старт

Требуется установленный [Node.js](https://nodejs.org/) версии 18 или новее.

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/YOUR_USERNAME/techservice.git
cd techservice

# 2. Установите зависимости
npm install

# 3. Запустите режим разработки
npm run dev
```

После запуска откройте [http://localhost:3000](http://localhost:3000) в браузере.

## Скрипты

| Команда         | Описание                              |
| --------------- | ------------------------------------- |
| `npm run dev`   | Запуск сервера разработки             |
| `npm run build` | Сборка проекта для продакшена         |
| `npm run start` | Запуск собранной версии               |
| `npm run lint`  | Проверка кода линтером                |

## Структура проекта

```
app/
├── page.tsx       # Главная страница: тексты, услуги, цены, шаги
├── globals.css    # Глобальные стили и адаптивная вёрстка
└── layout.tsx     # Корневой шаблон приложения
```

## Как изменить содержимое

Все тексты и данные находятся в начале файла `app/page.tsx`:

- `copy` — заголовки и подписи на русском (`ru`) и казахском (`kz`)
- `services` — список услуг
- `prices` — прайс-лист
- `steps` — этапы работы
- `instagram` — ссылка на профиль в Instagram

Чтобы изменить цены или добавить услугу, отредактируйте соответствующий массив **для обоих языков**, чтобы данные совпадали.

### Добавление нового языка

1. Добавьте код языка в тип `Language`
2. Добавьте переводы в объекты `copy`, `services`, `prices` и `steps`
3. Добавьте запись в массив `languages` — выпадающее меню обновится автоматически

## Деплой

Проще всего развернуть сайт на [Vercel](https://vercel.com/new):

1. Загрузите проект на GitHub
2. Импортируйте репозиторий на Vercel
3. Нажмите **Deploy** — при каждом push в ветку `main` сайт будет обновляться автоматически

# TechService — Сарыағаштағы компьютерлік көмек сайты

Сарыағаш қаласындағы (Қазақстан) компьютерлер мен ноутбуктерді баптау, жөндеу және қызмет көрсету қызметтеріне арналған бір беттік сайт. Сайт екі тілде — орыс және қазақ тілдерінде жұмыс істейді.

## Мүмкіндіктері

- Екі тілді интерфейс (орысша / қазақша), тілді таңдауға арналған ашылмалы мәзір
- Бөлімдер: басты бет, қызметтер, баға тізімі, «жұмыс қалай өтеді», байланыс
- Компьютерге, планшетке және телефонға бейімделген дизайн
- Сілтемелер арқылы бетті жұмсақ айналдыру
- Instagram арқылы байланысуға арналған батырмалар

## Технологиялар

- [Next.js](https://nextjs.org/) (App Router)
- [React](https://react.dev/) + TypeScript
- [Tailwind CSS](https://tailwindcss.com/) (қосылған) және `globals.css` ішіндегі жеке стильдер
- [lucide-react](https://lucide.dev/) — иконкалар

## Жылдам бастау

[Node.js](https://nodejs.org/) 18 немесе одан жаңа нұсқасы орнатылған болуы керек.

```bash
# 1. Репозиторийді көшіріп алыңыз
git clone https://github.com/YOUR_USERNAME/techservice.git
cd techservice

# 2. Тәуелділіктерді орнатыңыз
npm install

# 3. Әзірлеу режимін іске қосыңыз
npm run dev
```

Іске қосқаннан кейін браузерде [http://localhost:3000](http://localhost:3000) мекенжайын ашыңыз.

## Командалар

| Команда         | Сипаттамасы                            |
| --------------- | -------------------------------------- |
| `npm run dev`   | Әзірлеу серверін іске қосу             |
| `npm run build` | Жобаны өндіріске жинау                 |
| `npm run start` | Жиналған нұсқаны іске қосу             |
| `npm run lint`  | Кодты линтермен тексеру                |

## Жоба құрылымы

```
app/
├── page.tsx       # Басты бет: мәтіндер, қызметтер, бағалар, қадамдар
├── globals.css    # Жалпы стильдер және бейімделген дизайн
└── layout.tsx     # Қосымшаның негізгі шаблоны
```

## Мазмұнды қалай өзгертуге болады

Барлық мәтіндер мен деректер `app/page.tsx` файлының басында орналасқан:

- `copy` — орыс (`ru`) және қазақ (`kz`) тілдеріндегі тақырыптар мен жазулар
- `services` — қызметтер тізімі
- `prices` — баға тізімі
- `steps` — жұмыс кезеңдері
- `instagram` — Instagram профиліне сілтеме

Бағаны өзгерту немесе қызмет қосу үшін деректер сәйкес болуы үшін сәйкес массивті **екі тілде де** өңдеңіз.

### Жаңа тіл қосу

1. Тіл кодын `Language` түріне қосыңыз
2. Аудармаларды `copy`, `services`, `prices` және `steps` нысандарына қосыңыз
3. `languages` массивіне жазба қосыңыз — ашылмалы мәзір автоматты түрде жаңарады

## Орналастыру

Сайтты [Vercel](https://vercel.com/new) арқылы орналастыру ең оңай жол:

1. Жобаны GitHub-қа жүктеңіз
2. Репозиторийді Vercel-ге импорттаңыз
3. **Deploy** батырмасын басыңыз — `main` тармағына әрбір push жасалғанда сайт автоматты түрде жаңарады
